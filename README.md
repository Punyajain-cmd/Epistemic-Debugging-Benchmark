# Epistemic-Debugging-Benchmark
Building a new benchmark for the Models, enabling them to be more useful for AI4Science. Currently there is no benchmarks which test the models on meta-cognition abilities. The whole idea here is that can frontier LLMs can find the exact cause why does an experiment or why something failed from an engineering perspective, using human like intuition


The current frontier LLMs are really good and getting better in reasoning, in multi-modality data processing. It becomes very important to benchmark these models correctly, the major issues with the current benchmarks is that they are testing models in remembering tasks, out of distribution task. Benchmarks like Swe-Bench, Genome bench, Lab-Bench etc
